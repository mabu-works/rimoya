# リモや｜画面共有・リモート操作

ブラウザだけで PC の画面を共有し、離れた場所からマウス・キーボードで操作できる静的Webサイト＋Windows用入力エージェントです。

## 📖 概要

- **接続側ページ**（`index.html`）：スマホや別の PC のブラウザで開き、共有コードとパスコードを入力して接続します。映像の表示と、クリック・ドラッグ・ホイール・キー入力・テキスト送信を行います。
- **共有側ページ**（`host.html`）：画面を共有する PC のブラウザで開きます。ブラウザの画面共有（getDisplayMedia）で画面を取得し、接続の受付と入力の中継を行います。
- **入力エージェント**（`agent/`、Windows 用 `RimoyaAgent.exe`）：共有側 PC で起動しておく小さな常駐プログラムです。共有側ページから `ws://127.0.0.1:39011`（この PC の中だけ）で入力を受け取り、Windows の SendInput で実行します。閲覧だけなら不要です。

映像と操作信号は WebRTC（PeerJS）で暗号化され、端末同士で直接やり取りされます。接続の取り次ぎ（シグナリング）には PeerJS の公開サーバーを使います。NAT 越え用に Google の STUN と metered の公開 TURN（openrelay）を設定していますが、ネットワーク環境によっては接続できない場合があります。

## ✨ 機能

- 共有コード（6桁）＋パスコード（6桁）による接続。コードは共有のたびに変わり、ページを閉じると無効になります
- パスコードが一致した相手にだけ映像を送信し、入力を受け付けます（不一致は3回で切断）。同時に受け付ける接続は1つだけです
- マウス移動・クリック（左／中／右）・ドラッグ・ホイール、キーボード入力（KeyboardEvent.code ベース）、日本語テキストの直接入力（テキスト送信欄から）
- 接続側は全画面表示に対応。共有側は共有中の画面プレビューを表示します
- PWA 対応（ホーム画面に追加可能、オフラインキャッシュ。PeerJS 本体も同梱してキャッシュします）

## 📝 使い方

### 共有する側（PC）
1. 入力エージェント `RimoyaAgent.exe` を PC で起動します（操作を受け付ける場合のみ）。exe は配布されたファイルを使うか、`agent/build.bat` でビルドすると `agent/dist/` に生成されます。初回起動で「アクセスが拒否されました」と表示された場合は、エージェントの画面に表示される `netsh` コマンドを管理者権限で実行するか、エージェントを管理者として実行してください。
2. PC のブラウザで [rimoya.vercel.app/host.html](https://rimoya.vercel.app/host.html) を開き、「入力エージェント」が「接続済み」になっていることを確認します。
3. 「共有を開始」を押し、共有する画面（またはウィンドウ）を選びます。
4. 表示された共有コードとパスコードを接続側へ伝えます。

### 操作する側
1. [rimoya.vercel.app](https://rimoya.vercel.app) を開き、共有コードとパスコードを入力して「接続」を押します。
2. 映像が表示されたら、画面上のクリック・ドラッグ・ホイールとキー入力が共有側 PC に送られます。日本語の文章は「テキスト送信」欄から送ってください。
3. 終わったら「切断」を押します。

## 📋 技術メモ

- Web 側は素の HTML / CSS / JavaScript ＋ 同梱の PeerJS 1.5.4（`lib/peer.min.js`）のみ。実行時に外部 CDN へはアクセスしません（シグナリングと STUN/TURN を除く）。
- 接続プロトコルの定数・メッセージ検証・座標変換は `js/rimoya-core.js` に集約し、単体テスト（`tests/`）で固定しています。
- 対応モニターはプライマリモニターのみです（エージェントの座標変換がプライマリ画面基準）。
- エージェントは .NET 8 / C#、外部パッケージなし（標準ライブラリのみ）。ビルドは `agent/build.bat`（Windows）または `agent/build.sh` でワンコマンドです。純粋ロジックのテストは `agent/tests/run.sh` で実行できます。
- Service Worker（sw.js）が同一オリジンの GET をキャッシュします（キャッシュ名: rimoya-v1）。
- 共有コード・パスコードは共有側ページのメモリ上にだけ存在し、ストレージには保存しません。

## ⚠️ 注意

### 安全についての注意

- パスコードを知らない人は接続できませんが、**パスコードは接続を取り次ぐ相手にも渡る前提の簡易な仕組み**です。知らない人に共有コードとパスコードを教えないでください。
- 入力エージェントはこの PC の中（127.0.0.1）からしか接続を受けません。ただし、同じ PC 上の他のプログラムからも接続できるため、信頼できないプログラムを動かしている PC では使わないでください。
- 共有中は画面に映るものがすべて相手に見えます。見せたくないウィンドウがある場合は、画面全体ではなくウィンドウ単位の共有を選んでください。
- 無人での常時接続には対応していません（画面の選択と共有開始は、共有側 PC の前での操作が必要です）。
